# prueba-mcp-agent

Repositorio de prueba para el servidor MCP de GitHub (Model Context Protocol).

## Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/yahiralmendras22/prueba-mcp-agent.git
   cd prueba-mcp-agent
   ```

2. Instala las dependencias:
   ```bash
   npm install
   ```
